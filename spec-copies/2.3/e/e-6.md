# E.6: web UI messages, threads and reactions

Do not start this spec until every rule in E.1 to E.5 passes.

## Tips

- **Toolbar on hover.** Show it with `.message:hover .toolbar { display: flex; }`, with
  `display: none` otherwise. An element with `opacity: 0` still counts as visible.

## Uses

| Function | Used here for |
|---|---|
| The message, thread and reaction routes | Everything on this page |

## Adds

These `data-testid` values are also fixed:

| Element | Fixed name |
|---|---|
| Parts of each `message` row | `message-avatar`, `message-author`, `message-time`, `message-body` |
| Hover toolbar buttons | `message-edit-btn`, `message-delete-btn`, `open-thread-btn`, `reaction-button` |
| Text field shown while editing | `message-edit-input` |

## Rules

The rules run in a browser at 1280x900, already logged in through `huddle.token`. Each `message` in
`message-list` is one row. No rule may open an `alert()`, `confirm()` or `prompt()` dialog.

6.1 **Post.** Typing in `message-input` and clicking `send-btn` adds a `message` row. It shows
    `message-avatar`, the author's name in `message-author`, a time such as `3:07 PM` in `message-time`,
    and the text in `message-body`. The row is still there after a page reload.

6.2 **Empty message.** Clicking `send-btn` with an empty or spaces-only `message-input` adds no row.

6.3 **Edit.** `message-edit-btn` is hidden until the row is hovered. Clicking it shows
    `message-edit-input`, and pressing Enter there saves. The row shows the new text and the word
    `edited`, and both are still there after a page reload.

6.4 **Delete.** `message-delete-btn` in the hover toolbar removes the row, and it stays gone after a
    page reload.

6.5 **Threads.** `open-thread-btn` in the hover toolbar shows `thread-panel` to the right of
    `message-list`. Sending with `thread-input` and `thread-send` shows the reply in `thread-panel`,
    and the parent row shows `1 reply`. `close-thread` hides the panel.

6.6 **Reactions.** `reaction-button` in the hover toolbar shows `emoji-picker` with `display: grid` and
    several `emoji-option` elements. Clicking one adds a `reaction-chip` to the row showing the count
    `1`.
