# C.5: profiles

Do not start this spec until every rule in C.1 to C.4 passes.

## Tips

- Check time zones with Python's `zoneinfo`, and list `tzdata` in `/app/requirements.txt` so the
  names exist in a fresh container.

## Objects

- `UserObj`: `{id, username, display_name, timezone, avatar_url, status_text, status_emoji}`.

## Uses

Call these functions from earlier parts of the app. Do not write a second version of any of them.

| Function | Used here for |
|---|---|
| `require_user(request)`, `user_to_json(user)` | The caller; the `user` object |

## Adds

| Function | What it does |
|---|---|
| `update_profile(user, fields)` | Checks and saves any subset of the profile fields |
| `broadcast_user_updated(user)` | Sends `user.updated` to every open WebSocket on every node |

## Rules

Never return `422`. Bad input is `400`. Check the token first: no valid token is `401`.

5.1 **Read a user.** `GET /api/users/{id}` returns `200 {user}` with every `UserObj` field. An
    unknown id returns `404`. No token returns `401`.

5.2 **Update.** `PATCH /api/users/me` with any subset of `{display_name, timezone, avatar_url,
    status_text, status_emoji}` returns `200 {user}`. The fields sent change, the others stay the
    same, and the change is saved. No token returns `401`.

5.3 **Time zone.** `America/New_York` is accepted. `Not/AZone` returns `400`.

5.4 **Field lengths.** These limits are inclusive, and one character more returns `400`:
    `display_name` 80, `status_text` 100, `status_emoji` 32, `avatar_url` 1024.

5.5 **Broadcast.** A profile update sends `{"type": "user.updated", "user": UserObj}` to every open
    WebSocket on every node, including one that has not subscribed to anything. The frame has no
    `channel_id` and no `event_id`.

Every request must answer within 5 seconds.
